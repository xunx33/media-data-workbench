# 新媒体数据工作台

> **v3.6.0** — 多用户开箱即用：应用内登录（账号密码 + 自助改密）、数据按人隔离、AI 配置仅管理员可改、每日额度按人计（视频文案 20 次 / 数据分析 5 次）；全局深色模式。

覆盖 **抖音 / 快手 / 小红书 / 视频号** 4 个短视频平台的内容登记、数据录入、复盘分析、AI 智能分析与账号管理一体化工作台。

**技术亮点：零第三方依赖**——后端仅用 Node.js 内置模块，前端原生 JS/CSS，无框架、无构建、无 npm 包，装好 Node.js 即可运行。

## 快速开始

环境要求：**Node.js ≥ 14**，无其他依赖。

### 本地单人使用（Windows）

1. 双击 **`CreateShortcut.bat`**（仅首次）：桌面生成「新媒体数据工作台」图标
2. 以后双击桌面图标即可：后台静默启动服务并自动打开 `http://localhost:3000`（无黑窗口）

备选：`Start.bat`（效果同上）、`ViewStart.bat`（前台运行可看日志，排障用）。macOS / Linux：`node server.js`。

> 默认仅本机可访问；局域网访问加环境变量 `MCB_LAN=1`。默认为单用户免登录模式（`MCB_MULTIUSER=0`，多用户默认开启后本地调试想关掉时用）。

### 服务器多人使用（推荐架构）

**nginx（反向代理）+ Node（数据服务）**，完整配置见 `deploy/nginx.conf.example`：

1. 服务器启动：`MCB_ALLOWED_HOSTS=你的域名或IP node server.js`（Node 只监听本机 127.0.0.1）
2. **多用户模式默认开启**：首次启动自动创建 `admin` 账号并打印初始密码（在启动日志里，登录后请立即修改）；同事账号由管理员用一行命令创建：
   ```bash
   echo "Luna:$(openssl passwd -apr1 '初始密码')" >> data/mcb_users
   ```
3. 登录走应用内登录页，同事可自助修改密码；数据按人隔离在 `data/users/<账号>/`，AI 配置全局共享一份但**仅管理员可修改**（前端只读 + 服务端 403 双重拦截），Key 永不下发浏览器
4. 审计：`data/activity.log` 记录谁在何时登录、写了什么数据、调用了 AI

环境变量速查：`PORT`（端口，默认 3000）、`MCB_LAN=1`（监听全部网卡）、`MCB_MULTIUSER=0`（关多用户）、`MCB_ALLOWED_HOSTS`（Host 白名单）、`MCB_ADMIN_USERS`（多管理员名单）、`MCB_LLM_DAILY_LIMIT` / `MCB_REVIEW_DAILY_LIMIT`（AI 每日额度，默认 20 / 5）。

### PWA

浏览器打开工作台 → 地址栏「安装」图标 → 装为桌面/手机应用，离线可打开（需 HTTPS 或 localhost）。

## AI 功能

导航栏「🤖AI功能」页：上方配置大模型（OpenAI 兼容：DeepSeek / 豆包 / 千问 / 文心等），下方两个功能块：

- **AI 视频文案专家**：平台 + 选题（可选卖点）→ 一键生成 3 标题、视频描述与推荐标签，点击复制
- **AI 数据分析专家**：选周期 → 自动汇总数据 → 生成结构化分析报告（账号表现/亮点/问题/建议），可导出 HTML 报表（可打印/存 PDF）

**额度管理（服务端权威）**：额度在代理接口内校验扣减，绕过页面也无法超限；失败、超时、中途取消自动退还。视频文案每日 20 次、数据分析每日 5 次（按登录用户独立计数，环境变量可调），跨天自动重置，客户端无法自行清零。

## 日常使用流程

```
1. 今日待办 → 各平台 [+1] 登记今天发布的内容
2. 内容登记 → 补全标题/选题/链接
3. 录入数据 → 优先「表格一键解析」（上传平台导出的表，自动登记+填充）
4. 数据复盘 → 看周/月趋势与峰值，做复盘记录
5. 🤖AI功能 → 一键生成分析报告并导出
6. 导出数据 → Excel 汇报 或 HTML 打印存档
```

**表格一键解析要点**（内容登记页）：选平台 → 上传 `.xlsx/.csv/.tsv/.txt` → 预览确认 → 导入。同平台同一天多条作品按标题逐条登记互不覆盖，重复导入不重复；空标题笔记自动占位；非平台表格自动拦截；优先用 xlsx（编码安全）。

**数据导出**：「导出数据」选周期（全部/本周/本月）→ 选 Excel 或 HTML；「导出 JSON」为全量备份，「导入恢复」还原（导入前自动快照）。

## 数据与备份

所有数据在项目目录 **`data/`**：核心 5 类（内容/视频数据/复盘/账号数据/账号 ID）+ AI 配置 + 额度 + 审计日志；每次写入自动轮转 `.bak` 上一版。多用户模式核心数据在 `data/users/<账号>/` 按人隔离。

| 方式 | 场景 |
|---|---|
| 「导出 JSON」→ 他机「导入恢复」 | 换电脑迁移（推荐） |
| 直接拷贝 `data/` 文件夹 | 整机备份（需先停服务） |

> ⚠️ `data/` 不随代码仓库同步（已忽略），迁移务必单独带数据。

## 安全与可靠性

- **默认仅本机访问**（127.0.0.1）；外部访问走 nginx 反代 + Host 白名单（防 DNS rebinding）
- **应用内认证**：账密登录 + HMAC 签名会话 Cookie（HttpOnly / SameSite=Strict，30 天）；登录防爆破（5 分钟 10 次上限）；兼容 nginx `X-Remote-User` 注入的老式接法
- **静态服务防穿越**：拒绝 `..`、反斜杠与编码变体，`path.resolve` 归一化二次断言；`data/` 禁止直接下载
- **写接口**：强制 JSON Content-Type（免疫 CSRF）+ 体积上限（数据 10MB / LLM 2MB）；写入全局串行 + 原子替换 + `.bak` 轮转；批量写两阶段提交失败回滚
- **XSS 防御**：用户输入统一 `escapeHtml` 转义，链接 `safeUrl` 白名单，自动化测试以恶意输入跑真实渲染函数
- **数据保护**：核心数据加载失败禁止写入（防空数据覆盖）；导入前自动快照
- **Key 安全**：API Key 只存服务端，接口脱敏（仅 `hasKey`），页面不回显，编辑留空=保留
- **AI 代理防 SSRF**：禁止转发到本机/链路本地地址
- 响应统一 `nosniff`；js/css 内容指纹长缓存，改代码浏览器必然拿到新文件

## 常见问题

- **服务断开**：页面顶部提示后，用 `ViewStart.bat` 重启即可（数据不会丢）
- **快捷方式失效**：项目文件夹移动后重新双击 `CreateShortcut.bat` 重建
- **端口占用**：设 `PORT=3001` 再启动
- **同事忘记密码**：管理员在服务器上重置（删掉 `data/mcb_users` 中该账号行后重新 `echo` 写入新密码）
- **换电脑**：旧机「导出 JSON」→ 新机装 Node 启动 →「导入恢复」
