# 新媒体数据工作台

> **当前版本：v3.5.0** — 新增全局深色模式（顶栏一键切换、跟随系统偏好）；服务端安全加固（路径穿越拦截、接口校验、API Key 脱敏、可选令牌认证）；新增 **nginx 多用户部署模式**（每人一个账号、数据按用户隔离、写入审计）；移除 AI 拆解二创专家功能；一批数据一致性与显示修复。

覆盖 **4 个短视频平台（抖音 / 快手 / 小红书 / 视频号）** 的内容登记、数据录入、复盘分析、AI 智能分析与账号管理一体化工具。

适合新媒体运营人员每天使用：登记发布了什么 → 录入平台数据 → 查看趋势与复盘 → AI 自动分析 → 导出汇报。

**技术亮点：零第三方依赖**——后端仅用 Node.js 内置模块，前端不引入任何第三方库，安装 Node.js 即可运行。

## 一、功能总览

工作台共 6 个页面（顶部标签切换）：

| 页面 | 功能 |
|---|---|
| **今日待办** | 今日发布概览（短视频条数/平台覆盖/总登记）；各平台「+1」快速登记；视频平台直达快链（可自定义） |
| **内容登记** | 登记每条内容的标题/平台/选题/链接/日期；搜索（回车或点按钮）、按日期/平台/播放量筛选；每条内容可录入播放、完播率、均播时长、点赞、评论、收藏、推荐、分享、涨粉等数据；平台数据表格解析（上传平台导出的表格自动识别并录入） |
| **账号登记** | 账号 ID / 备注（一个平台可多个账号）；账号数据快照（发布量/粉丝量/播放/点赞/评论/转发），数据绑定到具体账号，每条数据与上一条记录的升降对比箭头 |
| **数据复盘** | 短视频数据看板（周/月切换、播放对比柱形图、趋势折线图带峰值标注，点击数据点直达发布日历）；周/月复盘记录 |
| **发布日历** | 按月查看每天各平台发布情况，点击日期看当日内容明细；法定节假日标记（2026-2028 年，含元旦/春节/清明/劳动节/端午/中秋/国庆） |
| **发布总览** | 月度汇总（本月数据总览 + 各平台数据占比饼图 + 各平台发布明细）；支持按月切换查看 |

### 核心能力

- **AI 大模型接入**：配置 OpenAI 兼容接口（DeepSeek/豆包/千问/文心等），支持 AI 视频文案专家、AI 数据分析专家，每日额度管理（chat/review 独立计数，每类每日 20 次上限；取消/失败自动退还）
- **深色模式**：顶栏 🌙/☀️ 一键切换，首次访问自动跟随系统偏好，选择持久保存，PWA 状态栏颜色同步
- **AI 数据分析专家**：选择总结周期，自动汇总数据，调用大模型生成结构化分析报告（账号表现/亮点/问题/建议），支持导出 HTML 报表
- **表格一键解析**：上传平台导出的数据表（xlsx/csv/tsv/txt），自动识别列并录入数据；小红书空标题笔记自动占位；非平台表格会被自动拦截
- **数据自动关联**：内容登记 ↔ 平台数据 ↔ 发布日历 相互关联，录一次数据全站联动
- **多格式导出**：全部/本周/本月三个周期，可选「Excel 表格」或「HTML 网页（可直接打印/存 PDF）」
- **AI 分析导出**：分析结果在新窗口直开 HTML 报表（与数据表报表同款样式，可打印/存 PDF）
- **全量备份恢复**：一键导出 JSON 全量备份（含全部数据），换电脑/迁移时一键导入恢复
- **桌面应用**：支持安装为桌面应用（PWA），离线也能打开
- **平台直达快链**：今日待办页视频平台快捷链接，支持自定义编辑

### 指标显示规则（视频数据栏）

| 情况 | 显示 |
|---|---|
| 平台不适用（如快手不记均播、小红书不记完播率、视频号不记收藏） | `-` |
| 适用但未录入 | 留空 |
| 适用且录入 0 | `0` |
| 适用且录入数值 | 格式化数字（如 `1.2w`） |

## 二、快速开始

### 环境要求

- Windows / macOS / Linux 电脑，安装 **Node.js ≥ 14**（无需安装任何依赖包，也不需要 Python）

### 启动方式（Windows，推荐：桌面快捷方式）

日常打开工作台，**只需要双击桌面上的「新媒体数据工作台」图标**：它会自动在后台启动服务并打开浏览器，全程**不弹黑窗口**。

首次使用需要先创建这个桌面图标（见下方「创建桌面快捷方式」）。

#### 创建桌面快捷方式（只做一次）

1. 打开项目文件夹（解压后的位置）
2. **双击 `CreateShortcut.bat`**，出现一行 `OK: shortcut created` 即成功
3. 桌面出现 **「新媒体数据工作台」** 图标 → 以后双击它即可启动

> - 该脚本**不依赖任何东西**（不需要安装 Python），任何 Windows 电脑都能用；内容为纯英文编码、中文以编码内嵌，**任何电脑上运行都不会乱码**
> - 换电脑 / 移动项目文件夹后，旧快捷方式会失效：重新双击一次 `CreateShortcut.bat` 即可重建（不影响 `data/` 里的数据）

#### 双击桌面图标后发生了什么（启动路径）

```
桌面快捷方式「新媒体数据工作台」
  └─ 由 wscript.exe 直接调用 start-hidden.vbs → 后台隐藏运行 node start-ui.js（自动检测端口、后台拉起服务，无窗口、不占用命令行）
     └─ 等待服务就绪 → 用默认浏览器打开 http://localhost:3000（跟随 PORT 环境变量）
```

> 服务会一直在后台运行（不占用任何窗口）。关掉浏览器页面**不影响服务**，数据照常保存；再次双击快捷方式即可重新打开页面。
> 端口被其他程序占用时，后台会给出「端口已被占用」的提示并自动退出，换 `set PORT=3001` 后再启动即可。

### 启动（Windows，备选）

没有快捷方式时，也可直接双击 **`Start.bat`**（效果与桌面快捷方式完全一致：服务后台隐藏运行、浏览器自动打开）。

- 端口默认 **3000**；服务已在运行时重复启动会自动复用
- 出问题排查用 **`ViewStart.bat`**（前台运行，服务日志直接显示在窗口，Ctrl+C 停止，窗口不自动关闭）

### 启动（macOS / Linux）

```bash
node server.js
# 浏览器访问 http://localhost:3000
```

> 默认仅本机可访问；需要局域网访问时加环境变量：`MCB_LAN=1 node server.js`

### 安装为桌面应用

浏览器打开工作台 → 地址栏右侧「安装」图标 → 安装「新媒体数据工作台」。之后可从桌面图标直接打开，离线可用。

### 部署到服务器（多人使用，数据按用户隔离）

需要给团队多人使用时，推荐 **nginx（登录认证）+ Node（数据服务）** 架构，完整示例见 `deploy/nginx.conf.example`：

1. 服务器上启动（Node 只监听本机，外部无法绕过 nginx）：
   ```bat
   set MCB_MULTIUSER=1
   set MCB_ALLOWED_HOSTS=你的域名或IP
   node server.js
   ```
2. nginx 开启 `auth_basic`，用 htpasswd 给每个同事建独立账号，并把登录名传给后端（`proxy_set_header X-Remote-User $remote_user;`）
3. 数据按登录用户分目录存放（`data/users/<账号>/`），同事之间数据完全隔离；AI 大模型 Key 全局共享一份（配置一次全员可用，且不会下发到任何浏览器）

管理员与权限：默认只有 `MCB_DEFAULT_USER`（默认 admin）可修改共享 AI 配置；如需多个管理员，设 `MCB_ADMIN_USERS=账号1,账号2`。普通用户读取 AI 配置只能看到脱敏结果，无 Key。

审计：nginx access.log 记录每次访问的账号；`data/activity.log` 记录谁在什么时间写了什么数据、谁调用了 AI。

## 三、AI 大模型功能

所有 AI 功能集中在导航栏右侧的「**🤖AI功能**」按钮页：上方配置大模型，下方「AI 视频文案专家」「AI 数据分析专家」两个功能块，各为**左右独立分栏面板**（左栏=参数设置/标题/说明，右栏=AI 输出结果）。两侧容器高度始终一致——结果再长也在右栏内滚动，不会拉高卡片。

### 配置入口

导航栏右侧「🤖AI功能」→ 填写 API Key（密码框，页面从不渲染真实 Key）→ 保存后锁定，测试连接验证可用性。

支持 OpenAI 兼容接口：DeepSeek、豆包、千问、文心、元宝、纳米等。

### AI 视频文案专家

选择平台 + 填写选题/主题（可选行业卖点），一键生成 3 个标题、视频描述与推荐标签，点击即可复制，结果可一键清空。

### AI 数据分析专家

选择总结周期（全部 / 本月 / 本周），点击「AI 数据分析」：

1. 自动汇总选定周期的视频平台数据（含各平台账号登记数据）
2. 调用大模型生成结构化分析报告（账号表现：总体表现 + 各平台表现 / 亮点和优势 / 问题和不足 / 下一步建议，无序「• 」列表）
3. 回复后可「HTML 网页直开」在新窗口打开报表（样式与数据表报表一致，可打印/存 PDF）

### 额度管理

- 每类每日上限 20 次（chat 视频文案 / review 数据分析独立计数）
- 跨天自动重置
- 额度用尽时 AI 功能按钮自动禁用

## 四、日常使用流程

```
1. 今日待办 → 各平台 [+1] 登记今天发布的内容
2. 内容登记 → 补全标题/选题/链接
3. 录入平台数据 → 优先「表格一键解析」，不用一条条录入（见下）
4. 数据复盘 → 看周/月趋势与峰值，做复盘记录
5. 🤖AI功能 → AI 数据分析专家，一键生成报告并导出 HTML
6. 导出数据 → Excel 汇报 或 HTML 打印存档
```

### 录入平台数据：优先「表格一键解析」（不用一条条录入）

短视频（抖音/快手/小红书/视频号）每天可能发好几条，逐条手输又慢又容易错。推荐做法：**把平台后台导出的数据表直接上传，一次自动完成「内容登记 + 数据填充」**，全站（数据复盘/发布日历）同步联动。

**操作步骤（在「内容登记」页顶部「解析数据表格」卡片中）：**

1. **选平台** — 下拉选择数据表所属平台（抖音/快手/小红书/视频号），页面会同步显示该平台常见的表头列名作参考
2. **上传表格** — 点击虚线框选择文件，或直接把文件拖进去；支持平台导出的 `.xlsx` / `.csv` / `.tsv` / `.txt`
3. **确认暂存预览** — 系统自动识别表头，显示「读取到 N 行数据 + 表头」；若表头特征与所选平台不符会给出警告，可切换平台重试，确认无误再继续
4. **点「导入解析」** — 内容自动登记 + 数据自动填充，并同步到发布日历；下方逐条列出已处理结果（标记「自动登记」或「已并入」）

**要点：**

- 同一平台同一天发多条作品，会**按标题逐条登记**，互不覆盖；重复导入同一份文件也不会重复
- 标题留空的笔记自动以「空标题」占位录入
- 非平台数据表 / 缺少日期列会被自动拦截
- 优先用 `.xlsx`（编码安全）；若源文件不是 UTF-8 编码，系统会检测到乱码并警告，改用 xlsx 或另存为 UTF-8 即可

### 数据导出

「导出数据」→ 选周期（全部/本周/本月）→ 弹窗选格式：

| 格式 | 用途 |
|---|---|
| **Excel 表格** | 下载 .xls 报表，可手动修改、可打印 |
| **HTML 网页** | 浏览器直接打开，Ctrl+P 打印或另存为 PDF |

导出内容根据数据自动裁剪：无数据的栏位（视频平台账号数据）自动隐藏。

「导出 JSON」用于全量备份；「导入恢复」用于还原备份。

## 五、数据与备份

工作台所有数据保存在项目目录 **`data/` 文件夹**：核心 5 类（内容登记、视频数据、复盘记录、账号数据、账号 ID），外加 AI 配置（llmConfig.json，含 Key，全局）、AI 每日额度（llmQuota.json）、审计日志（activity.log）；每次覆盖写入前自动轮转一份 `.bak` 上一版备份，导入备份前也会自动存一份 `import_snapshot_*.json` 快照。多用户模式下核心数据在 `data/users/<账号>/` 下按人隔离。

| 备份方式 | 适用场景 |
|---|---|
| 「导出 JSON」+ 他机「导入恢复」 | 换电脑 / 远程迁移（推荐，简单可靠） |
| 直接拷贝 `data/` 文件夹 | 整盘迁移 / 同机备份（需先停服务） |

> ⚠️ 注意：`data/` 目录不随代码仓库同步（已自动忽略）。迁移时**务必单独带上数据**，否则新环境只有空壳没有数据。

## 六、技术架构

### 零依赖设计

- **后端**（`server.js`）：Node.js 内置模块实现静态文件服务 + JSON 数据读写 API + LLM 转发代理
  - `GET  /api/data/{key}`：读取数据（不存在返回 `[]`；llmConfig 脱敏只返回 `hasKey` 标记，不返回 Key）
  - `POST /api/data/{key}`：单键写入（**原子写 + .bak 轮转 + 全局写队列串行**，多请求/多用户并发不交错）
  - `POST /api/data/batch`：批量写入（**两阶段提交 + 失败回滚**：先全部写 tmp、再全部 rename；中途失败时已替换文件用旧内容还原、未替换的删 tmp，尽量保持跨文件一致）
  - `POST /api/llm/chat`：大模型代理转发（请求缺 Key 时自动用服务端保存的配置兜底）
  - `GET  /api/me`：当前登录用户（多用户模式）
  - **缓存自动刷新**：js/css 按内容计算哈希指纹自动注入 `?v=`，改代码后浏览器必然拿到新文件，无需手动维护版本号；带指纹资源配 `immutable` 长缓存，`index.html` 走 `no-cache`
- **前端**：原生 JS + CSS，无框架、无构建、无 npm 依赖

### 安全设计

- **默认仅本机访问**：服务默认绑定 `127.0.0.1`；确需外部访问时用 `MCB_LAN=1`（个人临时用）或按上节走 nginx 多用户架构（团队用）
- **静态服务穿越防护**：拒绝 `..` 片段与反斜杠/编码变体（`%5C`、`%2e%2e`），`path.resolve` 归一化后二次断言仍在项目内；`data/` 目录禁止直接访问，数据只走 API
- **接口校验**：Host 白名单（`MCB_ALLOWED_HOSTS`，防 DNS rebinding）；写接口强制 `Content-Type: application/json`（免疫表单 CSRF）+ 请求体大小上限（数据 10MB / LLM 2MB）
- **访问令牌（可选）**：设置 `ACCESS_TOKEN` 环境变量后全站需登录（内置登录页，Cookie HttpOnly + SameSite=Strict）
- **多用户身份**：`MCB_MULTIUSER=1` 时信任 nginx 注入的 `X-Remote-User`，按用户隔离数据并写入审计日志
- **XSS 防御**：所有用户输入统一经 `escapeHtml()` 转义（含引号）；链接经 `safeUrl()` 仅放行 http/https；AI 返回文本不进入内联事件；自动化回归测试以恶意输入跑真实渲染函数验证
- **数据保护**：核心数据加载失败时禁止写入（防止空数据覆盖磁盘真实数据）；导入备份自动清洗 id 字段并存导入前快照
- **API Key 安全**：Key 只存服务端 `data/llmConfig.json`，读取接口脱敏（只有 `hasKey` 标记），页面从不渲染真实 Key，编辑留空=保持原 Key
- **保存失败提示**：数据写入失败不再静默，页面顶部会显示警告横幅，直到下次保存成功
- **响应头**：统一 `X-Content-Type-Options: nosniff`，杜绝 MIME 嗅探

### 手写 xlsx 解析

不依赖任何第三方库，自行实现 ZIP 解压 + sharedStrings + sheet XML 解析，支持 xlsx/csv/tsv/txt 多格式表格导入。

### PWA 离线支持

Service Worker 采用「数据请求永远走网络 + 静态资源 stale-while-revalidate」策略，安装后离线可用。

│       └── table-parser.js # 表格解析引擎（xlsx/csv/tsv）

## 九、常见问题

- **服务断线提示**：页面顶部提示「后台服务已断开」→ 用 `ViewStart.bat` 重新启动即可（数据不会丢）
- **桌面快捷方式失效/打不开**：项目文件夹被移动或换电脑后，旧快捷方式会指向不存在的位置；重新双击一次 `CreateShortcut.bat` 即可重建（不影响 `data/` 里的数据）
- **端口被占用**：启动时后台会提示「端口已被占用」；设置环境变量 `PORT=3001` 后再启动，浏览器会自动访问新端口
- **手机也想用**：服务默认仅本机可访问，需先以 `MCB_LAN=1` 启动（见「安全设计」）；然后手机连同一 WiFi，浏览器访问 `http://电脑IP:3000` 并「添加到主屏幕」；需在外面访问可另配内网穿透（Tailscale 等）
- **换电脑迁移**：旧机「导出 JSON」→ 新机装 Node + 启动 → 「导入恢复」
